## About

I build web apps end to end: a Vue and Next.js frontend, JavaScript services on the backend, and the Postgres database behind them. I also write C# and Python when a project needs them. I like building the whole thing myself, from the screen a person sees to the code that answers it.

<br/>

## Devyrse

I own and build [Devyrse](https://devyrse.com), a team chat app for software teams. It's one product with a website, an API, a desktop app and a Windows setup, and it has a public changelog and a status page.
